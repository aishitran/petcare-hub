# Petcare Hub — Nền tảng Cứu trợ & Nhận nuôi Thú cưng

Petcare Hub là nền tảng cộng đồng phi lợi nhuận hướng tới việc chung tay giúp đỡ những bạn nhỏ khi gặp khó khăn, bị nạn, cần nơi an toàn hoặc tìm kiếm một mái ấm yêu thương.

## Tính năng chính

- **Tìm kiếm & Nhận nuôi (Adoption)**: Hồ sơ chi tiết các bé chó, mèo cần tìm chủ mới với quy trình khảo sát nhận nuôi 6 bước kỹ lưỡng và an toàn.
- **Kêu gọi Cứu hộ Khẩn cấp (Rescue Appeals)**: Đăng tin và theo dõi tiến độ các ca cứu trợ khẩn cấp tại hiện trường.
- **Mạng lưới Trạm Cứu trợ & Nhu yếu phẩm**: Cập nhật danh sách các trạm cứu hộ trên toàn quốc cùng nhu cầu nhu yếu phẩm (thực phẩm ~kg, vật tư y tế, chăm sóc & vệ sinh, chuồng trại) và cơ chế gửi shipper/trao trực tiếp.
- **Hệ thống Quản lý Đơn & Lịch hẹn**: Đặt lịch phỏng vấn, duyệt đơn chính thức, danh sách dự phòng và check-in sau nhận nuôi.
- **Đa ngôn ngữ & Chế độ Sáng/Tối**: Hỗ trợ đầy đủ tiếng Việt (VI) và tiếng Anh (EN), cùng giao diện Tối/Sáng bảo vệ mắt.

## Công nghệ sử dụng

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## Cài đặt & Chạy ứng dụng

```bash
# Cài đặt các gói phụ thuộc
npm install

# Khởi chạy môi trường phát triển (Development Server)
npm run dev

# Đóng gói sản phẩm (Build for Production)
npm run build
```
