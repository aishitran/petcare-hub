# PetCare Hub - Pet & Adoption Service

## Responsibilities
- Pet profile CRUD, media upload handling
- Multi-criteria pet search & filtering (Breed, Age, Size, Health, Location)
- 5-step Adoption Process Management:
  1. Profile & Application Submission
  2. Owner/Shelter Review & Interview
  3. Offline Meet & Compatibility Assessment
  4. Non-commercial Adoption Commitment Signing
  5. Post-adoption periodic check-ins & health tracking
- Admin Pet Post Approval & Decline workflow (with decline reasons)

## Port
- **Port**: `8002`
- **Database**: PostgreSQL / MongoDB (`petcare_pet_db`)
